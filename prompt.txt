## PAGE 4 — Block Simulator (simulator.html)

Build an interactive blockchain mining simulator using pure JavaScript and the Web Crypto API (SHA-256). No external libraries.

**What to build:**

**Block 1:**
- Input field: Block Data (text)
- Display: Previous Hash = "0000000000000000" (hardcoded genesis)
- Display: Nonce (auto-incremented)
- "Mine Block" button — increments nonce until SHA-256 hash starts with "00" (proof-of-work simulation)
- Display the resulting hash
- Show "✅ Block Valid" in green when mined

**Block 2:**
- Automatically reads Block 1's hash as its Previous Hash
- Has its own Block Data input field
- Has its own "Mine Block" button with the same proof-of-work logic
- If Block 1's data changes after mining, Block 2 should turn "❌ Block Invalid" in red automatically

**Key behavior:** Changing Block 1's data after it has been mined must immediately invalidate Block 2 — this demonstrates blockchain immutability.

Use the Web Crypto API like this for hashing:
async function sha256(message) {
  const msgBuffer = new TextEncoder().encode(message);
  const hashBuffer = await crypto.subtle.digest('SHA-256', msgBuffer);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}
